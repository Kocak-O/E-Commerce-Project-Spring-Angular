🛒 E-Commerce Web Application
This project is a full-stack e-commerce web application built with Spring Boot on the backend and Angular on the frontend.

🎯 Project Purpose
The main goal of this project is to gain hands-on experience with Spring Security and session-based authentication using JSESSIONID.
The project focuses on understanding and implementing:
Secure user authentication and authorization
Session management in Spring Boot
A session-based shopping cart system
User sessions and protected backend endpoints

🧱 Technology Stack
Backend
Java
Spring Boot
Spring Security
RESTful APIs
Session Management (JSESSIONID)

Frontend
Angular
TypeScript
HTML & CSS
HTTP-based communication with the backend

✨ Features (Planned / In Progress)
User registration and login
Session-based shopping cart
Product listing
Secured REST endpoints
Role-based access control

📌 Motivation
This project is a learning-oriented portfolio project created to strengthen my understanding of:
secure web application development,
session-based authentication mechanisms,
and the interaction between Angular frontends and Spring Boot backends.
It is designed to reflect real-world backend security concepts commonly used in enterprise applications.
